# Spec — Permissão Full do Agent Hive

O toggle vive na seção Agent Hive das Configurações da IDE, no cartão de segurança que já existe. Não cria tela nova nem muda o Orb.

Estados: desligado (padrão, checkbox vazio) e ligado (checkbox marcado + uma linha de aviso com texto, não só cor). O aviso usa o mesmo sinal de erro já usado pelo modo experimental.

Contraste: texto `--text` / `--text-dim` sobre `--surface-card`. Nenhum hex novo.
